# نسخهٔ ۱٫۴٫۰ — بازطراحی گرافیک دانشجویی + مستند فنی (v1.4.0)

تاریخ: ۱۴۰۵/۰۹/۰۱ (2026-11-22)

## ۱) بازطراحی گرافیک — «جذاب دانشجویی»

پاسخ به بازخورد «گرافیک سامانه دل‌برو و جذاب برای دانشجو نیست» — ارتقای عمیق سیستم
طراحی بدون تغییر هیچ API یا رفتار صفحات:

- **پالت شاد چندرنگ**: علاوه بر نیلی/فیروزه‌ای/طلایی، چهار رنگ مکمل (بنفش، صورتی،
  نارنجی، لیمویی) به توکن‌ها و Tailwind اضافه شد — برای کارت‌های آماری، میان‌برها و
  انواع مأموریت (در حالت روشن و تاریک هر دو کنتراست WCAG حفظ شده).
- **داشبورد**: ردیف میان‌برهای گرادیانی چهارگانهٔ (مأموریت‌ها/پاداش/دستاوردها/پیشنهادها)
  با آیکن متحرک؛ کارت‌های امتیاز با حباب آیکن رنگی و عدد درشت؛ **حلقهٔ پیشرفت
  گرادیانی (SVG)** برای مسیر سطح + نشان «✓» گرادیانی برای سطوح کسب‌شده.
- **مأموریت‌ها**: حباب آیکن و رنگ اختصاصی برای هر `mission_kind` (kickoff=طلایی،
  چالش=فیروزه‌ای، کارگاه=صورتی، …)؛ بنر رویداد آغازین با قاب گرادیانی متحرک؛ نوار
  ظرفیت گروه‌های علاقه‌ای.
- **فضای دستاوردها**: نوار رنگی بالای هر روایت بر اساس نوع داستان + آیکن بزرگ با
  افکت wiggle؛ کارت CTA با قاب گرادیانی.
- **آنبوردینگ**: جشن کاغذرنگی (confetti) هنگام صدور نشان «اولین قدم» + قاب گرادیانی +
  نشانگر مراحل گرادیانی با تیک.
- **پوسته**: آیتم فعال سایدبار با نوار فیروزه‌ای و آیکن bounce؛ چیپ‌های ناوبری موبایل
  با آیکن؛ اسکلت بارگذاری درخشان (shimmer).
- **همه با احترام به `prefers-reduced-motion`** و بدون شکستن آزمون‌ها (Vitest ۶/۶ پاس).
