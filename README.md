# باشگاه دانشجو۳۶۰ — زیرسیستم ۱۷ اکوسیستم «دانشجو۳۶۰»

**«باشگاه هوشمند پیشرفت، مشارکت و تجربهٔ دانشجو»** — FastAPI + React + PostgreSQL + Redis/Celery، ماژولار مونولیت، RTL فارسی.

> **صداقت تحویل:** هر ادعا به کد/آزمون واقعی در همین ریپو ارجاع دارد. آنچه فقط «تولید شده» و آنچه «اجرا و آزموده شده» صریحاً جدا شده‌اند. نتیجهٔ واقعی آزمون‌ها: `backend/TEST_RESULTS.md` — ۲۸/۲۸ پاس روی PostgreSQL 16.2 واقعی (بدون SQLite) + ۸ آزمون SSO (v1.1.0).

## اجرای سریع

```bash
# مسیر A — بدون Docker (الگوی سندباکس، دارای pgserver محلی):
cd backend && export DATABASE_URL="postgresql://postgres:@/club360_dev?host=/home/z/my-project/.pgdata"
alembic upgrade head && python -m app.seed && uvicorn app.main:app --port 8000
cd ../frontend && npm install && npm run dev   # http://localhost:3000

# مسیر B — Docker Compose (db+redis+backend+worker+beat+frontend+nginx):
cp .env.example .env && docker compose up --build

# مسیر C — نسخهٔ قابل‌حمل (بدون نصب پایتون/PostgreSQL — v1.1.0، پورت 8089):
npm --prefix frontend run build && python3 scripts/build_portable.py --platform both
# استخراج خروجی و اجرای start.bat (ویندوز) یا ./start.sh (لینوکس)
```

## تجربهٔ باشگاه — v1.3.0 (مأموریت واقعی، شروع فوری، دستاورد قابل‌نمایش)

تجربه از «امتیاز گرفتن برای فعالیت» به «ماجراجویی، ساختن، ارتباط و دستاورد قابل‌نمایش» منتقل شد؛ منطق امتیاز/سیاست/دفترکل دست‌نخورده ماند و همهٔ ایده‌ها در چارچوب آیین‌نامه (داوطلبانه، بدون اثر بر نمره، بدون رقابت فرساینده) پیاده شدند:

- **شروع فوری «اولین دستاورد در ۱۵ دقیقه»** (`/onboarding`): سه قدم — انتخاب مسیر انتخابی، انتخاب علاقه‌ها (حداکثر ۵)، بازکردن اولین مأموریت. پس از عضویت، کاربر خودکار به همین جریان می‌رود؛ نشان «اولین قدم» بلافاصله و فقط یک‌بار صادر می‌شود (`onboarding_profiles` + `_ensure_first_badge`).
- **مسیرهای انتخابی ملموس**: سازنده/کاوشگر/همیار/متخصص/راهبر — هر کدام برچسب تجربهٔ همان سه مسیر مصوب سطح‌بندی است (skill/learning/collaboration)؛ منطق امتیاز بدون تغییر.
- **مأموریت‌های واقعی با خروجی ملموس**: فیلد `mission_kind` (رویداد آغازین، چالش ۲۰ دقیقه‌ای، مأموریت یک‌روزه، کارگاه آزمایشی، یک عصر یک مهارت، مسئلهٔ واقعی، راهنما) + `output_fa` (خروجی ملموس)، `duration_label_fa`، `team_size_hint`، `interest_tags` — در فهرست مأموریت‌ها نمایش و با فیلترهای «کوتاه و کم‌تعهد» و «تیمی و واقعی» قابل تفکیک است.
- **گروه‌های کوچک علاقه‌ای**: `GET /api/v1/groups` با هدف روشن، زمان محدود و خروجی مشخص («یک هفته، سه نفر، یک ایدهٔ قابل‌ارائه») — چهار گروه نمونه در seed.
- **پاداش‌های تجربه‌ساز**: فیلد `kind` (experience/choice/resource/physical) + فیلتر «فقط پاداش‌های تجربه‌ساز» — کارگاه با متخصص، بازدید آزمایشگاه، بازخورد رزومه/نمونه‌کار، فرصت ارائهٔ ایده، ابزار تکمیلی غیرضروری، حق انتخاب موضوع رویداد بعدی، منتورینگ.
- **نشان‌های داستان‌محور**: فیلد `story_fa` — «اولین قدم، سازنده، هم‌مسیر، حل‌گر، پیوسته»؛ هر نشان می‌گوید چه کاری انجام شده و چرا ارزشمند است.
- **دعوت دوست برای مأموریت مشترک**: `POST /club-experience/invites` فقط برای عضو فعلی مأموریت؛ کد یک‌بارمصرف؛ هیچ امتیازی برای تعداد دعوت‌ها نیست (پیام صریح در UI).
- **فضای دستاوردها به‌جای رتبه‌بندی** (`/showcase`): روایت‌های کوتاه «این تیم چه ساخت؟ / چه مسئله‌ای حل کرد؟ / چه مهارتی تجربه شد؟» فقط با رضایت (`has_consent`)، بدون هیچ فیلد رتبه/امتیاز.
- **رویداد آغازین**: مأموریت kind=kickoff با کارت ویژه + پیام معرفی تجربه‌محور در صفحهٔ عضویت (سه پیام کوتاه صفحهٔ اول).
- مایگریشن `d4e5f6a7b8c9`؛ ماژول جدید `app/modules/club_experience`؛ نقاط پایانی `/api/v1/club-experience/onboarding|invites|showcase`.
- اصلاح رگرسیون v1.2: دیالوگ‌های مودال (پاداش/دعوت) به‌دلیل transform انیمیشن ورود، زیر صفحه رندر می‌شدند — اکنون با portal به `document.body`.
- آزمون‌ها: **۴۸/۴۸ پاس** (۸ آزمون جدید تجربهٔ باشگاه) — `backend/TEST_RESULTS.md`.

## تضمین‌های کلیدی (آزمون‌شده روی PostgreSQL واقعی)

- ارسال چندبارهٔ رویداد ⇒ **فقط یک اثر** (کلید یکتای مرکب + Inbox + Idempotency)
- رزرو ظرفیت/امتیاز در **یک تراکنش**؛ مسابقهٔ ظرفیت ⇒ یک برنده (Row Lock + قید یکتا)
- خرج هم‌زمان چنددستگاهی ⇒ هرگز منفی/مضاعف نمی‌شود
- Retry Worker ⇒ بدون اثر مضاعف؛ اصلاح ⇒ سند جبرانی قابل پیگیری
- مصرف پاداش، **پیشرفت تجمعی را کم نمی‌کند**؛ اعتراض پذیرفته‌شده هر سه را اصلاح می‌کند
- قطع LMS ⇒ بدون کاهش امتیاز و بدون پرچم تقلب
- triggerهای بی‌ردپا + قید توازن در COMMIT (در اجرای واقعی یک خطای طراحی را گرفت و اصلاح شد)
- سقف امتیاز در پردازش موازی رعایت می‌شود؛ رزرو منقضی آزاد می‌شود
